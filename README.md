# 🧺 LaundryKu

### Sistem Informasi Manajemen Laundry Berbasis Web

## ⚙️ Instalasi dan Menjalankan Project

1. Clone repository:

   ```bash
   git clone https://github.com/putrihima909/projek-rpl-laundryKu.git
   ```

2. Masuk ke direktori project:

   ```bash
   cd projek-rpl-laundryKu
   ```

3. Simpan folder project di direktori `htdocs` XAMPP.

4. Install dependency Composer:

   ```bash
   composer install
   ```

5. Salin `.env.example` menjadi `.env`, kemudian sesuaikan konfigurasi database.

6. Siapkan database MySQL sesuai konfigurasi aplikasi.

7. Jalankan Apache dan MySQL melalui XAMPP.

8. Buka aplikasi melalui browser sesuai konfigurasi server lokal.
